## ⚙️ **Run a Program**

Install **GCC**, then compile your file:

    gcc program.c -o program

Run it on **Linux or macOS**:

    ./program

Run it in **Windows PowerShell**:

    .\program.exe

📝 Replace **program.c** with the filename you want to compile.
